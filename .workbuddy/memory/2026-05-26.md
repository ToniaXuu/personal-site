# 2026-05-26

## 修复 personal-site 三个 Bug

### Bug 1：深色主题首次加载白色闪现
- **根因**：`useTheme.ts` 只在 `onMounted()` 中应用 `dark` class，在此之前页面已按浅色主题渲染
- **修复**：在 `nuxt.config.ts` 的 `app.head.script` 中注入阻塞内联脚本，在 DOM 渲染前读取 localStorage 并立即添加 `dark` class
- 修改文件：`nuxt.config.ts`

### Bug 2：浅色主题下博客代码块看不清
- **根因**：`--prose-pre-bg` 在浅色模式下设为 `rgba(0,0,0,0.03)`（几乎白色），且未定义前景色
- **修复**：
  - 浅色模式 `pre` 块改为深色背景 `#1e293b` + 浅色文字 `#e2e8f0`
  - 新增 `--prose-pre-text`、`--prose-code-bg`、`--prose-blockquote-bg`、`--prose-table-border`、`--prose-th-bg` 等变量
  - `.blog-prose` 内显式定义 `pre`、`code`、`blockquote`、`table` 样式，使用 `!important` 确保优先级
- 修改文件：`assets/css/main.css`

### Bug 3：博客页面无过渡动画 / 点击后反应慢
- **修复**：
  - `app.vue`：添加 `<NuxtLoadingIndicator>` 全局导航进度条 + `<NuxtPage>` 页面过渡动画（fade+slide）
  - `pages/blog/index.vue`：添加骨架屏加载态，使用 `lazy: true` 实现客户端即时渲染
  - `pages/blog/[...slug].vue`：添加骨架屏加载态 + 404 模板处理，使用 `lazy: true`，SSR 404 用 `import.meta.server` 判断
- 修改文件：`app.vue`、`pages/blog/index.vue`、`pages/blog/[...slug].vue`

## 构建验证
- `nuxt build` 成功，零错误
